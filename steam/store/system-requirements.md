# Kayboro: Steam store page requirements and driver disclosure

Paste these into Steamworks > Edit Store Page > System Requirements (Windows). The "Additional Notes" line is
the store-page disclosure of the Kayboro Virtual Screen Driver; the EULA (EULA.txt) and the in-app notice
disclose it again at install and on first launch.

## Minimum

| Field | Value |
| --- | --- |
| OS | Windows 10 version 2004 (64-bit) or Windows 11 |
| Processor | 4-core CPU, 2.5 GHz |
| Memory | 4 GB RAM |
| Graphics | DirectX 11 GPU |
| Storage | 600 MB available space |
| Additional Notes | Installs the free Kayboro Virtual Screen display driver (Windows asks for administrator approval once). It powers Hide Game Window and is removed when you uninstall Kayboro. Game capture needs the game in windowed or borderless mode. |

## Recommended

| Field | Value |
| --- | --- |
| OS | Windows 11 (64-bit) |
| Processor | 6-core CPU, 3.0 GHz |
| Memory | 8 GB RAM |
| Graphics | DirectX 12 GPU |
| Storage | 600 MB available space |
| Additional Notes | Same as minimum. A second monitor is not needed: Hide Game Window runs the game on an invisible screen. |

## "About This Game" paragraph (end of the description)

> **Hide Game Window:** Kayboro comes with the free, open-source Kayboro Virtual Screen driver. It runs your
> game on an invisible screen so the only copy you see is the one inside your shell. Windows asks for your
> approval once when it is installed, and uninstalling Kayboro removes it.
