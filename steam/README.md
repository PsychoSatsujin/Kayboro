# Steam builds

Everything needed to upload a Kayboro build to Steam with SteamPipe.

1. Build the Windows depot content: `npm run dist:steam` (writes `dist/win-unpacked/`).
2. Check it: `BUILD_FOR_TESTING.bat nobuild` runs `Kayboro.exe --self-test` and prints PASS or FAIL.
3. Upload: `powershell -ExecutionPolicy Bypass -File steam/upload.ps1 -AppId <app id> -DepotWin <depot id> [-Preview]`.
   The script fills `scripts/*.vdf.template`, finds `steamcmd` (install the Steamworks SDK if it is missing) and asks for your Steam login when it runs. It never stores credentials.
4. In the Steamworks partner site, set the uploaded build live on a branch.

`steam_appid.txt` is never shipped (the depot templates exclude it). For local testing outside Steam, put a `steam_appid.txt` with `480` next to the exe.

- `achievements.json`: Kayboro's own achievements (API names, names, descriptions). Enter them in Steamworks with the icons from `achievement-icons/`.
- `assets/`: store and library images, generated by `node tools/brand/build.cjs`.

## Kayboro Virtual Screen Driver: install and disclosure

Kayboro ships a display driver (`driver\` next to `Kayboro.exe`) for Hide Game Window. Players are told before
it is installed and can remove it at any time:

| Where | What the player sees | Set up by |
| --- | --- | --- |
| Store page | System Requirements "Additional Notes" and a paragraph in About This Game | Paste from `steam/store/system-requirements.md` |
| First install (Steam) | The EULA, which has a section on the driver | Steamworks app admin: add `EULA.txt` as the app's EULA, shown on first launch |
| First-time setup (Steam) | Windows' administrator prompt while Steam runs `driver\kbvdd-setup.exe install` | `installscript.vdf` (added by `upload.ps1` when the driver is in the build) |
| Installer (non-Steam) | The EULA on the license page, then Windows' administrator prompt | `nsis.license` + `build/installer.nsh` |
| First launch (Kayboro) | A one-time "Kayboro Virtual Screen is installed" notice | `src/renderer/index.html` `#driverNotice` |
| Any time | Install Driver button (Displays section), Device Manager, uninstall | Kayboro, Windows |

Release checklist for the driver:

1. Build it signed: SignPath CI in the driver's public repository (see `driver/README.md`), then point
   `KBVDD_PACKAGE` at the signed package before `npm run dist:steam`.
2. `npm run dist:steam` stages it into `build\driver` and the build copies it to `dist\win-unpacked\driver`.
3. `steam\upload.ps1` writes `installscript.vdf` and flags it in the depot.
4. In Steamworks, set `EULA.txt` as the EULA and paste the store text. Have the EULA reviewed by someone
   qualified before release.
